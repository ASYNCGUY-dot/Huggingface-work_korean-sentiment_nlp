# 한국어 감성분석 | 포트폴리오 안내

## 해결하려는 문제
검증 점수가 높은 분류 모델이 실제 문장에서도 잘 작동하는지 확인하고자 했습니다.
NSMC 영화 리뷰를 사용해 klue/roberta-base를 파인튜닝하고, 별도 테스트와 Gradio 추론 화면까지 연결했습니다.

## 구현과 역할
개인 학습·실험 프로젝트로 데이터 비교, 학습, 평가, 모델 공개와 추론 화면을 구성했습니다.
PyTorch, Transformers, Hugging Face, Gradio를 사용했습니다.

## 판단과 검증 근거
- [상세 보고서](../REPORT.md), [실측 기록](../PROGRESS.md): 데이터를 달리한 실험과 실패를 기록했습니다.
- [학습 노트북](../day3_finetuning/colab_train_nsmc.ipynb): 학습 조건과 실행 흐름
- [평가 코드](../day4_evaluation/): 혼동행렬과 정밀도·재현율 관점 평가
- [추론 화면](../day5_deploy/02_serve_my_model.py): 확신도 경고와 입력 한계 안내

## 결과를 읽는 방법
README에는 NSMC test split 2,000건에서 정확도 88.0%, F1 0.8769가 기록돼 있습니다.
이 수치는 해당 실험의 결과이며 이번 포트폴리오 정리에서 재학습·재평가하지 않았습니다.
검증과 테스트 점수가 같다는 사실만으로 과적합이 전혀 없다고 단정할 수는 없습니다.
소수 실전 예문에서 나온 정답률은 별도 테스트셋의 정확도와 구분해야 합니다.
영화 리뷰 밖의 상품평·뉴스·업무 문서에 성능을 일반화할 수 없고, 어휘 일치 기반 경고는 완전한 도메인 탐지기가 아닙니다.

설치와 실행은 [README](../README.md), 실험의 상세 조건은 [REPORT](../REPORT.md)를 확인해 주세요.
