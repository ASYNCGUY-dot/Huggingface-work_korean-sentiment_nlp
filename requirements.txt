#   3) pip 업그레이드:  python -m pip install --upgrade pip
#   4) 설치          :  pip install -r requirements.txt
#   5) VS Code에서 Ctrl+Shift+P → "Python: Select Interpreter" → .venv 선택

# huggingface_hub : 모델 다운로드 / 허브 업로드 / hf CLI

#     처음엔 >=0.33.5 만 적었다가 pip install -U 로 1.26.0 이 깔렸고,
#     transformers 4.44.2 가 "huggingface-hub<1.0 필요"라며 import 자체를 거부했습니다.
#   ★ 하한(>=0.34)도 필요합니다. 새 `hf` CLI 가 0.34 부터 들어왔습니다.
