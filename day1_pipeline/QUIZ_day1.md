## Part A

**Q1. → 4번**
모델 선택은 사람이 하는 판단입니다. pipeline은 "지정하면 자동으로 로드"해줄 뿐, "무엇이 이 문제에 맞는지"는 결정해주지 않습니다. 지정을 생략하면 기본값이 붙을 뿐입니다.

**Q2. → 2번 (PyTorch)**
`"tf"`는 TensorFlow. 참고로 transformers v5부터는 TensorFlow 지원이 제거되어 PyTorch만 남습니다.

**Q3. → 4번 (`english`)**
모델 이름에 언어가 명시돼 있으면 그 언어 전용입니다. 다국어 모델은 보통 `multilingual` 또는 `xlm` 이 들어갑니다.

**Q4. → 2번**
자동 선택되는 모델이 `distilbert-base-uncased-finetuned-sst-2-english` 입니다. 에러는 나지 않고 **조용히 틀린 답**을 냅니다. 이게 더 위험합니다.

**Q5. → 3번**
모델 config에 라벨 이름 정보가 없으면 허깅페이스가 `LABEL_0`, `LABEL_1` 을 자동 생성합니다.

**Q6. → 2번**
인코더(언어 이해)는 학습됐지만 분류 헤드는 새로 만들어집니다. 실행 시 `Some weights are newly initialized: ['classifier.weight']` 경고가 바로 그 증거입니다.

## Part B

**Q11.**
```
① 토크나이저 자동 로드 & 문장을 토큰 → 숫자 ID로 변환
② 모델 가중치 다운로드 / 캐시에서 로드
③ 숫자를 텐서로 변환하여 모델에 투입
④ 모델이 raw 점수(logits) 출력
⑤ softmax로 확률 변환 + 라벨 이름 매핑
```

**Q12. 예시 답안**
> 베이스 모델은 한국어를 유창하게 하는 외국인이고, 파인튜닝된 모델은 한국어도 하면서 영화 평론 훈련까지 받은 사람이다. 전자에게 "이 리뷰 좋아? 나빠?"라고 물으면 말은 알아듣지만 판단 기준이 없어서 아무 말이나 한다.
>
> 기술적으로는: 베이스 모델은 언어 이해(인코더)만 사전학습된 상태이고, 파인튜닝된 모델은 그 위에 특정 태스크용 분류 헤드까지 학습이 끝난 상태다.

**Q13. 예시 답안**
```
① 태스크 확인   : sentiment-analysis / text-classification 인가
② 언어 확인     : 한국어를 학습했는가 (모델 카드의 학습 데이터 확인)
③ 도메인 확인   : 금융 데이터로 학습됐는가 → snunlp/KR-FinBert-SC
   + 라벨 의미 확인 : positive가 '기분'인지 '주가 방향'인지
   + 파인튜닝 여부 확인 : LABEL_0이 나오면 탈락
```

**Q14. 예시 답안 (3개 이상이면 정답)**
```
1. 모델을 지정했는가? → 생략하면 영어 전용 모델이 붙는다
2. 그 모델이 한국어를 학습했는가?
3. 파인튜닝된 모델인가? (LABEL_0이 나오는지 확인)
4. 점수가 0.7 미만인가? → 모델이 헷갈리고 있다는 신호
5. 모델 카드에서 라벨의 의미를 확인했는가?
```

**Q15. 수정 코드**
```python
from transformers import pipeline

classifier = pipeline(
    "sentiment-analysis",
    # 문제 1: klue/roberta-base 는 파인튜닝 안 된 베이스 모델
    #        → 감정 분류용 파인튜닝 모델로 교체
    model="nlptown/bert-base-multilingual-uncased-sentiment",
    # 문제 2: tokenizer 를 다른 모델 것으로 지정 → 토큰 분해 방식이 달라 의미 왜곡
    #        → 아예 생략하는 것이 가장 안전 (자동으로 짝인 것이 로드됨)
    framework="pt",
)
print(classifier("이 영화 정말 재밌어요!"))
```
