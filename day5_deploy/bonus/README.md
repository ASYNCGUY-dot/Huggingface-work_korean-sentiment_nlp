## 🎯 이 보너스의 진짜 목적

기능 구경이 아닙니다. **STAGE 1~5에서 배운 것이 모달리티를 넘어 성립하는지** 확인하는 겁니다.

| STAGE 1~5에서 배운 것 | 여기서 다시 나타나는 곳 |
|---|---|
| 모델은 "모르겠다"를 못 한다 | ViT가 그래프를 억지로 1,000개 중에 분류 |
| 학습 범위 밖은 못 한다 | ImageNet에 없는 개념 / 영어 전용 감정 모델 |
| 클래스 수가 기준선을 정한다 | 7지선다는 14.3%가 기준선 |
| 확신도를 봐야 한다 | ViT 확신도 30% 미만이면 경고 |
| 모델은 입력이 없어도 출력한다 | Whisper 환각 (무음에서 문장 생성) |

> **모달리티가 바뀌어도 성질은 같습니다.**
> 텍스트에서 배운 의심의 습관이 이미지·음성에도 그대로 적용됩니다.

### 새로 배우는 것 2가지

**① 지연 로딩(lazy loading)**
모델을 미리 다 불러오면 앱 시작이 몇 분씩 걸립니다. 필요할 때 부르고 캐시합니다.

**② 오류 전파(error propagation)**
```
Whisper 90% × 번역 85%  =  전체 76%
```
모델을 연결하면 정확도가 **곱해집니다.** 그래서 중간 결과를 반드시 보여줘야 합니다.
