## 이 스테이지의 핵심 — 데모와 서비스의 차이

`02_serve_my_model.py` 는 그냥 모델을 감싸지 않습니다.
**STAGE 4에서 배운 안전장치를 전부 넣었습니다.**

| 장치 | 없으면 | 어디서 배웠나 |
|---|---|---|
| 빈 입력 방어 | 앱이 에러로 죽음 | 5일차 수업 |
| 임계값 슬라이더 | 0.5 고정 | STAGE 4 M2 |
| 확신도 표시 | 얼마나 믿을지 모름 | STAGE 1 |
| 사람 검토 경고 | 애매한 걸 자동 판정 | STAGE 4 M4 |
| 도메인 밖 경고 | 엉뚱한 입력에 확신 | STAGE 1·4 |
| 한계 명시 | 사용자가 과신 | STAGE 4 모델카드 |

> **★ 이 6개가 없으면 '데모', 있으면 '서비스'입니다.**

## 🚨 배포의 3대 함정 (미리 알아두세요)

### 1️⃣ 모델 크기 — 443MB

```
GitHub          : 파일 하나당 100MB 제한
허깅페이스 Spaces : Git LFS 필요, 느림
```

**해결:** 모델은 **모델 허브**에 따로 올리고, 앱에서는 이름으로 불러옵니다.

```python
pipeline(model="사용자명/모델명")   # Space에는 코드만 (6KB)
```

### 2️⃣ requirements.txt — 로컬과 **정반대**

```
로컬 : transformers==4.44.2    ← 고정 (재현성)
배포 : transformers            ← 느슨 (호환성)
```

수업 노트에도 기록된 실패입니다. 버전을 고정했다가 빌드가 계속 깨졌고, 버전명을 지우니 성공했습니다.

### 3️⃣ 파일명은 반드시 `app.py`

Spaces가 이 이름을 찾습니다. `main.py`, `demo.py` 안 됩니다.
