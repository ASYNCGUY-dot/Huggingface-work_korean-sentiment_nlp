## Part A

**Q1. → 3번**
분류 헤드는 랜덤에서 시작해 본격적으로 학습되고, 인코더도 함께 미세하게 조정됩니다. (인코더를 얼려두는 방식도 있지만 기본값은 함께 학습입니다)

**Q2. → 3번**
2e-5 ~ 5e-5가 정석. 0.01 같은 값을 쓰면 사전학습된 지식이 파괴됩니다.

**Q3. → 2번**
loss가 극단적으로 낮은 건 자랑이 아니라 암기 신호입니다. 실습에서 이게 실전 80%로 이어졌습니다.

**Q4. → 2번**
`grad_norm`은 "얼마나 더 배울 게 남았나"의 지표입니다. 0에 가까워지면 학습이 사실상 끝난 것입니다.

**Q5. → 3번**
실제 문제에서 100%는 거의 나오지 않습니다. 데이터 누수, 라벨 오류, 검증셋 편향을 먼저 의심합니다.

**Q6. → 2번**
학습 데이터 600문장 전체에 `좋`이 단 한 번도 없었습니다. 모델에게는 외계어입니다.

**Q7. → 2번**
`지루했어요`는 학습에 있었는데도 틀렸습니다. 단어가 아니라 구절 전체를 통으로 외웠기 때문입니다.

**Q8. → 2번**

**Q9. → 3번**
데이터가 적을 때는 경량 모델이 가성비·성능 모두 앞섭니다. "닭 잡는 데 소 잡는 칼 쓰지 마라."

## Part B

**Q11. 예시 답안**
> 문장 하나당 37만 개의 조절 손잡이가 배정된 셈이다. 모델 용량이 데이터 규모에 비해 압도적으로 크면, 일반적인 규칙을 배우는 것보다 데이터를 통째로 외우는 편이 훨씬 쉽다. 그래서 과적합이 거의 필연적으로 일어난다.

**Q12. 예시 답안**
> "데이터 부족"이라 진단하면 같은 스타일로 양만 늘리게 된다. 그런데 템플릿 데이터를 600 → 6000으로 늘려도 `좋다`는 여전히 없으므로 사각지대가 그대로 남는다.
>
> "어휘가 좁다"라고 진단해야 다양한 표현을 확보하는 방향으로 간다. 진단이 틀리면 노력의 방향이 통째로 틀어진다.

**Q13. 예시 답안**
> 검증 데이터가 학습 데이터와 같은 템플릿으로 만들어졌다. 8:2로 아무리 정교하게 나눠도 양쪽 다 템플릿이므로, 검증은 "외운 걸 다시 물어보는" 시험이 된다.
>
> 검증 데이터는 실제 서비스에 들어올 데이터와 닮아야 한다. 원본이 편향되면 분할 방법이 아무리 좋아도 소용없다.

**Q14. 예시 답안**
> **경량 모델이 유리한 조건:** 데이터가 수백 건 수준이고, 판단 근거가 특정 단어의 등장 여부일 때. 학습이 1초 안에 끝나고 왜 그렇게 판단했는지 설명도 가능하다.
>
> **BERT가 확실히 이기는 조건:** 데이터가 수천~수만 건이고 문맥 이해가 필요할 때. `"나쁘지 않아요"`(부정어 뒤집기), `"기대했던 것과는 다르네요"`(함축) 같은 것은 단어 통계로 절대 못 잡는다.

**Q15. 문제 3개와 수정**

```python
from transformers import AutoModelForSequenceClassification, TrainingArguments, Trainer
from datasets import load_dataset

ds = load_dataset("some_dataset")
# 문제 ①: 정렬된 데이터를 앞에서 자르면 한쪽 라벨만 뽑힐 수 있음
#          → 반드시 shuffle 먼저
small = ds["train"].shuffle(seed=42).select(range(1000))

# 문제 ②: num_labels 미지정 → 기본값이 2가 아닐 수 있고 의도가 드러나지 않음
model = AutoModelForSequenceClassification.from_pretrained(
    "bert-base-multilingual-cased", num_labels=2
)

args = TrainingArguments(
    output_dir="./out",
    # 문제 ③: learning_rate 0.01 은 BERT 파인튜닝에 500배 큼 → 사전학습 지식 파괴
    learning_rate=2e-5,
    # (추가) epoch 20 도 과함. 데이터가 충분하면 2~3이면 됩니다.
    num_train_epochs=3,
)

# (추가) eval_dataset 과 compute_metrics 가 없어 성능 측정이 불가능합니다.
trainer = Trainer(model=model, args=args, train_dataset=small)
trainer.train()

model.save_pretrained("./my_model")
# (추가) 토크나이저도 반드시 같이 저장해야 나중에 불러올 수 있습니다.
```
